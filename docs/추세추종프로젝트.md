-   차트 캐시: `ohlcv_cache` + `chart_cache.py`, 마커 캐시 `chart_marker_cache.py`(30분 갱신).

### 4.3 판정 규칙 (보호된 규칙 — `.claude/rules/chart-buy-label.md`, `chart-sell-label.md`)

Regular BUY : (저가 ≤ BB하단  또는  종가가 BB하단을 아래→위 복귀) AND RSI < 임계 AND MACD 모멘텀 상승
SQZ BUY     : 전봉 squeeze > 0 → 현봉 0 (스퀴즈 해제) AND 모멘텀 > 0 AND 모멘텀 상승
Regular SELL: (종가 ≥ BB상단  또는  상단에서 아래로 복귀) AND RSI > 60
SQZ SELL    : 스퀴즈 해제 AND 모멘텀 < 0
쿨다운      : 동일 방향 5봉.  BUY→SELL 전환은 즉시 허용
차트 라벨   : BUY = "관심", SELL = "매도"(041 리네임)

| 민감도 | RSI Buy | BB %B | 필요 조건 수 |
| --- | --- | --- | --- |
| strict | < 30 | ≤ 0.05 | 4/4 |
| normal | < 35 | ≤ 0.15 | 3/4 |
| sensitive | < 40 | ≤ 0.25 | 2/4 |

BUY 신호의 본질은 **볼린저 하단 + 과매도 RSI = 평균회귀 진입**이다. 여기에 EMA 추세 필터를 결합해 "상승추세 속 눌림목 매수"로 설계되었다. (추세추종 관점 평가는 14장)

## 5\. 스캔 시스템

### 5.1 전체 시장 스캔 (스캔1, `full_market_scanner.py`)

\_analyze\_ticker 파이프라인
\[0\] 사전 제외: 캔들 < 60 · RSI ≥ 80 & 스퀴즈 없음 · 마지막 봉 7일 이상 stale
\[1\] \_is\_dead\_cross     : EMA5<10<20<60<120 전체 역배열 → 스킵
\[2\] \_check\_buy\_signal\_precise : Pine 시뮬 마지막 마커가 BUY/SQZ BUY & 10거래일 이내
\[2.5\] \_is\_pullback     : EMA20>60>120 (장기 상승) & EMA5 하락(단기 눌림)
\[2.6\] is\_large\_cap     : KOSPI200/KOSDAQ150/S&P500 (ETF·크립토는 통과)
\[3\] \_passes\_volume\_filter : 신호일 거래량 > 직전 5일 평균 × 1.5
→ chart\_buy  (KR 5 + US 5 표시 상한)

| 카테고리 | 조건 |
| --- | --- |
| `picks` 추천 | 스퀴즈 ≥ 2 + BULL 추세 + EMA20 ≥ EMA50 (시장별 Top 3) |
| `max_sq` 폭발 임박 | 스퀴즈 = 3 + BULL + EMA20 ≥ EMA50 (시장별 Top 5) |
| `chart_buy` | 위 파이프라인 전체 통과 |
| 신뢰도 점수 | 스퀴즈×25(최대75) + BULL 15 + RSI<40 10 + %B<0.3 5 + MACD>0 5 + 거래량>1.0 5 |

추세 판정 `check_trend`(`scan_conditions.py`): EMA20>50>200 & 가격>EMA20 & EMA20 5봉 기울기>0 → BULL / 역배열 & 가격<EMA20 → BEAR / 그 외 NEUTRAL. 조건 로직은 `/conditions` 페이지에 공개(027).
